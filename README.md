# Stoker

`~/.claude/projects` 의 Claude Code 세션 트랜스크립트를 직접 읽어 토큰과 환산 비용을 집계하는
로컬 모니터링 대시보드. 웹폰트까지 파일에 심어 두었으므로 나가는 요청은
**계정 한도 조회 하나뿐**이고, `--no-live-limits` 로 끄면 아무 요청도 나가지 않습니다.

이름은 불을 지켜보며 연료를 대는 화부(stoker)에서 왔습니다. 이 도구가 하는 일도
진행 중인 5시간 블록이 얼마나 빠르게 타고 있는지 지켜보는 것입니다.

## 빠른 시작

```bash
node src/cli.js --serve --open     # 실시간 대시보드 (기본 포트 7331)
node src/cli.js                    # 정적 HTML 생성 + 터미널 요약
node src/cli.js --json             # 집계 결과를 JSON 으로
```

런타임 의존성이 없습니다. Node 20 이상이면 그대로 실행됩니다.
데스크톱 앱으로 쓰려면 아래 **데스크톱 앱** 을 보세요(Electron 은 devDependency 입니다).

## 데스크톱 앱

### 리포트 출력

데스크톱 앱에서 지금 보고 있는 화면을 그대로 PDF 로 저장하거나 인쇄합니다.

- **파일 > PDF 저장 (다운로드 폴더)** (`Cmd+S`) — 대화상자 없이 바로
  `~/Downloads/stoker-YYYY-MM-DD-HHMM.pdf` 로 떨어집니다(A4)
- **파일 > 인쇄…** (`Cmd+P`)
- 트레이 메뉴에도 `PDF 저장 (다운로드 폴더)` 이 있습니다

대화상자가 없으면 저장됐는지 알 방법이 사라지므로 결과를 알림으로 알립니다.
알림을 누르면 Finder 에서 그 파일을 보여 줍니다. 실패해도 이유를 알립니다 —
조용히 성공하거나 조용히 실패하는 출력 기능은 없는 것보다 나쁩니다.

같은 분에 두 번 저장하면 `-2`, `-3` 을 붙여 앞의 리포트를 덮지 않습니다.

인쇄용 스타일이 따로 있습니다. 종이에서는 **항상 라이트 테마**로 찍고(다크는
잉크만 먹고 읽기도 나쁩니다), 기간 필터·갱신 입력·테마 버튼·실시간 표시등처럼
조작용이거나 종이에서 의미가 없는 요소는 뺍니다. 막대와 배지 색은 유지합니다.

접힌 데이터 표(`<details>`)는 출력 직전에 열고 끝나면 되돌립니다 — CSS 로는
펼 수 없어서, 그냥 두면 종이에 차트만 남고 숫자가 빠집니다.

정적 HTML 이 필요하면 CLI 로도 됩니다: `node src/cli.js --out ./report.html`.
파일 하나로 완결되고 폰트까지 들어 있어 오프라인에서도 열립니다.

### 알림

세션 한도가 임계값을 넘거나 소진 상태가 나빠지면 macOS 알림을 띄웁니다.
메뉴바를 보지 않아도 알 수 있게 하는 것이 목적입니다.

| 계기 | 예 |
|---|---|
| 한도 임계값 통과 | `사용 한도 80% 넘음` · 현재 세션 81% · 2시간 5분 후 재설정 |
| 소진 상태 악화 | `소진 상태 주의` · 안정 에서 올라갔습니다 |
| 재설정 임박 | `한도 재설정 임박` · 8분 후 재설정 · 현재 60% |

```bash
npm run app -- --notify-at 70,90   # 임계값 지정 (기본 80,95)
npm run app -- --no-notify         # 끔
npm run app -- --notify-test       # 이 기기에서 알림이 뜨는지 확인
```

핵심은 **중복 억제**입니다. 조건이 아니라 **전이**를 봅니다 — 임계값을 넘는
순간에만 한 번 울리고, 아래로 내려가면 다시 무장합니다. 상태는 나빠질 때만
알리고(좋아지는 것은 알릴 이유가 없습니다), 앱을 켠 첫 관측으로는 놀래키지
않습니다. 재설정 임박은 50% 미만이면 소음이라 건너뜁니다.

**낡은 한도 값으로는 알리지 않습니다.** 캐시로 폴백한 상태에서 알리면 거짓
경보이거나 이미 늦은 경보입니다.

#### macOS 알림이 안 뜬다면

서명이 없으면 번들 식별자가 `Electron` 으로 남아 macOS 가 알림을 **조용히
거부합니다**(`UNErrorDomain 오류 1`). 그래서 빌드에 애드혹 서명을 붙입니다
(`build/adhoc-sign.cjs`) — 이것만으로 식별자가 `dev.duksang.stoker` 로 잡혀
로컬 알림이 정상 동작합니다.

거부되면 조용히 실패하므로 트레이 메뉴에 `알림 차단됨: <이유>` 로 드러내고,
`--notify-test` 로 직접 확인할 수 있게 했습니다. 그래도 안 뜨면 시스템 설정 >
알림에서 Stoker 를 허용하거나 집중 모드를 확인하세요.

### 메뉴바

앱을 실행하면 메뉴바에 상주합니다. 창을 닫아도 종료되지 않고 메뉴바에 남습니다
(종료는 트레이 메뉴의 `Stoker 종료` 또는 Cmd+Q).

메뉴바 제목에는 **실제 세션 한도 사용률**을 올립니다 — 환산 추정 금액보다
이것이 사실입니다. 숫자 자체가 신호라서 상태 단어를 덧붙이지 않습니다
(`71%` 와 `96%` 는 읽으면 압니다).

```
불꽃 71%        한도를 실시간으로 읽은 경우
불꽃 주의 $261  한도가 낡았거나 없어 금액으로 되돌아간 경우
불꽃            진행 중인 블록도 한도도 없음
```

낡은 퍼센트를 그냥 띄우면 여유 있다고 오해하게 만들므로, 그때는 금액으로
되돌아가고 상태 단어를 붙여 주의를 끕니다. 금액은 센트를 버려 폭이 흔들리지
않게 했습니다(`●▲■` 글리프는 16px 에서 앱 아이콘과 뭉개져 쓰지 않습니다).

- **아이콘 클릭** — 창 열기/숨기기
- **우클릭** — 블록 사용·소진 속도·예상 총액·남은 시간·기간 비용·코드 변경,
  그리고 `지금 갱신` / `대시보드 열기` / `브라우저에서 열기` / `종료`

메뉴바는 창과 같은 `/api/report` 를 읽으므로 두 화면의 수치가 어긋나지 않습니다.
갱신 주기는 `--refresh` 값을 따르되 최소 15초, 갱신을 끈 경우 60초입니다.

트레이 아이콘은 `npm run icons` 로 다시 만듭니다. `qlmanage` 로 SVG 를 변환하면
알파가 흰 배경으로 평탄화돼 메뉴바에 통짜 사각형이 찍히므로, zlib 만 써서
알파까지 직접 래스터화합니다.


```bash
npm install          # electron, electron-builder (devDependency)
npm run app          # 앱으로 실행
npm run app:pack     # 패키징만 (release/mac-arm64/)
npm run app:dist     # 배포본 (macOS dmg·zip / Windows nsis / Linux AppImage)
```

`electron/main.js` 는 기존 서버를 **앱 프로세스 안에서** 포트 0(OS 가 빈 포트 배정)으로
띄우고 그 주소를 창에 로드합니다. 집계·렌더 코드는 CLI 와 완전히 같은 것을 씁니다.

창은 `nodeIntegration: false`, `contextIsolation: true`, `sandbox: true` 로 열고
외부 링크는 기본 브라우저로 넘깁니다. 렌더러에 노출하는 API 는 없습니다.

`--refresh <초>` 를 앱에도 넘길 수 있습니다: `npm run app -- --refresh 10`

코드 서명은 하지 않습니다. macOS 에서 처음 열 때 Gatekeeper 경고가 나오면
우클릭 → 열기로 실행하세요.

## 대시보드가 답하는 질문

| 밴드 | 질문 | 핵심 지표 |
|---|---|---|
| 사용 한도 | 한도까지 얼마 남았나 | 세션·주간 한도의 실제 사용률(%) |
| 진행 중인 5시간 블록 | 지금 안전한가 | 소진 속도, 블록 예상 총액, 상태 등급 |
| 일별 소비와 변화 | 추세는 어떤가 | 일별 비용, 전일·전주 대비 |
| 코드 변경량 | 코드는 얼마나 바뀌었나 | 추가·삭제 줄 수, 건드린 파일, 프로젝트별 순위 |
| 모델 · 프로젝트 · 실행 주체 | 무엇이 비용을 먹는가 | 비용 순위와 비중 |
| 토큰 구성과 캐시 효율 | 토큰은 어디로 가는가 | 토큰 수 기준 / 비용 기준 구성 |
| 시간대별 분포 | 언제 쓰는가 | 24시간 히스토그램 |
| 상위 세션 | 어느 세션이 무거웠는가 | 세션별 비용 |

### 집계 기간 고르기

프리셋(7일 / 30일 / 90일 / 전체) 외에 날짜를 직접 지정할 수 있습니다. 시작일과 종료일을
고르고 `적용` 을 누르면 서버가 그 구간만 다시 집계합니다. 경계는 집계 타임존 기준으로
**시작일 0시부터 종료일 23:59:59.999 까지** 하루 전체를 덮습니다.

주기 갱신이 돌아도 고른 구간은 유지됩니다. `해제` 를 누르면 30일 프리셋으로 돌아갑니다.
정적 HTML 로 내보낸 경우엔 다시 집계할 서버가 없어 날짜 선택이 비활성화됩니다.

### 자동 갱신 주기

기본 30초입니다. 두 곳에서 바꿉니다.

```bash
node src/cli.js --serve --refresh 45   # 실행 시 기본값
```

실행 후에는 대시보드 헤더의 `갱신 [ ] 초` 입력란에 **원하는 값을 직접 적습니다.**
옆의 `지금 갱신` 버튼은 주기와 무관하게 한 번 즉시 갱신합니다 — 갱신을 멈춰 둔
상태에서 필요할 때만 불러오는 용도입니다.
프리셋(5·10·30·60·300초)은 입력란의 제안 목록으로만 뜨고, 그 밖의 값도 얼마든지 됩니다.

- 허용 범위 **5~3600초**, `0` 은 갱신 멈춤
- 범위를 벗어나거나 정수가 아니면 거부하고 이전 값으로 되돌립니다
  (하한 5초는 수집기를 두드리지 않을 선입니다)
- 검증 기준은 서버가 `refreshBounds` 로 내려주므로 CLI 와 대시보드가 항상 같습니다
- 고른 값은 브라우저에 저장돼 다시 열어도 유지되고, 서버 기본값보다 우선합니다
- `0` 이면 주기 폴링과 탭 복귀 갱신이 모두 멈춥니다
- 정적 HTML 로 내보낸 경우엔 갱신할 서버가 없어 입력란이 비활성화됩니다

### 사용 한도는 어디서 오나

계정의 **실제 한도 사용률**은 트랜스크립트에 없습니다. 트랜스크립트에는 토큰 수만 있고
한도와 그 환산 방식은 서버가 갖고 있습니다. 그래서 Claude Code 가 쓰는 것과 같은
엔드포인트를 직접 호출합니다.

```
GET https://api.anthropic.com/api/oauth/usage
Authorization: Bearer <OAuth 액세스 토큰>
```

토큰은 `CLAUDE_CODE_OAUTH_TOKEN` → `~/.claude/.credentials.json` → macOS 키체인
순으로 찾습니다. 못 찾으면 캐시로 되돌아갑니다.

**이 엔드포인트는 레이트 리밋이 있습니다.** 실측하면 `429` 와 `Retry-After: 203` 이
돌아옵니다 — Claude Code 가 값을 캐시하는 이유입니다. 그래서 이 도구도:

- 최소 **5분** 간격으로만 호출합니다(대시보드 갱신 주기는 5초까지 내려갈 수 있습니다)
- `429` 를 받으면 서버가 알려준 시간만큼 쉽니다. 자체 하한이 더 길면 더 긴 쪽을 지킵니다
- 쉬는 동안에는 마지막 성공값을 재사용하고, 그것도 없으면 파일 캐시를 씁니다

**출처를 항상 표시합니다.** `방금 서버에서 받아온 값` / `캐시 · N분 전 값` 으로 구분하고,
캐시로 되돌아갔으면 그 이유(`HTTP 429`, `레이트 리밋 — 76초 후 재시도` 등)까지 적습니다.
실시간인 줄 오해하면 안 되기 때문입니다.

폴백용 캐시는 `~/.claude.json` 의 `cachedUsageUtilization` 입니다. `limits`
배열(kind/percent/severity/resets_at/scope)만 쓰고, 같은 파일의 내부 코드명 키들은
뜻을 확신할 수 없어 건드리지 않습니다. 계정 식별자는 담지 않습니다.

**응답 형태가 바뀌면 캐시로 되돌아갑니다.** `limits` 배열은 있는데 항목에서
`percent` 를 하나도 못 읽으면 필드 이름이 바뀐 것으로 보고 폴백합니다 — 통과시키면
"실시간 성공, 항목 0개" 가 되어 화면에는 아무것도 안 나오면서 실시간인 줄 오해합니다.
빈 배열은 "한도 없음" 이라 정상으로 봅니다.

**만료된 토큰으로는 호출하지 않습니다.** 자격증명의 만료 시각을 먼저 보고,
지났으면 요청 없이 `OAuth 토큰이 만료됐습니다 — Claude Code 를 한 번 실행하면
갱신됩니다` 라고 알립니다. `401` 을 받았을 때도 같은 문구를 씁니다.

토큰은 로그·에러 메시지·JSON 출력에 절대 실리지 않습니다. 방어선이 셋입니다:

1. 열거 불가 속성에 담아 `JSON.stringify` 로 새지 않게 합니다
2. 토큰을 아는 지점에서는 `redact` 로 정확히 지웁니다
3. 토큰을 모르는 경계(HTTP 응답 핸들러 등)에서는 `scrubSecrets` 가 토큰처럼
   생긴 문자열을 패턴으로 한 번 더 지웁니다

`test/leak-guard.test.js` 가 불변식을 강제합니다 — `accessToken` 을 참조할 수 있는
파일은 `credentials.js` 와 `usage-api.js` 뿐이고, 그 외 소스에는 `console` 출력이
없어야 하며, 자격증명 객체를 통째로 직렬화하는 코드가 없어야 합니다. 파일이 늘면
테스트가 깨집니다.

이 한도는 절대 기준이므로, 아래 **상태 등급**(본인 이력 백분위)과는 다른 지표입니다.
둘 다 보여 주는 이유는 한도 조회가 실패·지연될 수 있고, 등급은 항상 최신이기 때문입니다.

### 상태 등급은 어떻게 정해지나

계정마다 한도가 다르므로 절대 기준을 쓰지 않습니다. 진행 중 블록의 **예상 총액**을
**본인의 과거 블록 분포**와 비교합니다.

- `안정` 중앙값 미만
- `주의` 중앙값 ~ 상위 10%
- `높음` 상위 10% 이상

## 옵션

```
--serve            로컬 서버 실행 (변경된 파일만 다시 파싱)
--port <번호>      서버 포트 (기본 7331)
--days <일수>      터미널 요약 기간 (기본 30)
--out <경로>       HTML 저장 위치 (기본 ./dist/dashboard.html)
--tz <타임존>      집계 기준 타임존 (기본: 시스템 설정)
--refresh <초>     자동 갱신 주기 (기본 30, 5~3600, 0 은 끔)
--no-live-limits   계정 한도를 서버에 묻지 않고 캐시만 사용
--no-notify        알림 끔
--notify-at <목록>  알림 임계값 (기본 80,95)
--open             브라우저로 열기
--help, -h         도움말
```

## 집계 방식

- **대상**: `~/.claude/projects/**/*.jsonl` 전부. 메인 세션뿐 아니라
  `<session>/subagents/` 와 `subagents/workflows/` 아래의 서브에이전트·워크플로 트랜스크립트도 포함합니다.
- **코드 변경량**: Edit/Write 툴 결과 레코드에서 뽑습니다. Edit 은 `structuredPatch` 의
  diff hunk 에서 `+`/`-` 줄을 세고, 새 파일 생성은 patch 가 비므로 `content` 전문의 줄 수를 씁니다.
  Claude Code 관리자 화면의 lines added/removed 와 같은 지표입니다.
- **중복 제거**: `message.id` + `requestId` 기준. 같은 응답이 여러 파일에 복제돼도 한 번만 셉니다.
- **5시간 블록**: 첫 활동을 정시에 앵커하고, 5시간 이상 공백이 생기면 새 블록으로 봅니다.
- **증분 파싱**: 파일 크기와 수정시각이 그대로면 다시 읽지 않습니다.
  최초 전체 스캔 약 2.4초(275개 파일 / 622MB), 이후 갱신은 수 밀리초.

## 비용은 "환산 참고값"입니다

공개 API 단가로 계산한 값이며 실제 청구액이 아닙니다. 구독 요금제라면
"같은 작업을 API 로 했다면" 값으로 읽으세요.

캐시 단가는 input 단가의 배수입니다 — 5분 쓰기 ×1.25, 1시간 쓰기 ×2, 읽기 ×0.1.

같은 계열이라도 버전에 따라 단가가 다릅니다(Opus 4.1 은 $15, 4.5 부터 $5). 그래서

`단가 추정` 으로 표시합니다.

Claude 4.6 이상은 1M 컨텍스트까지 표준 단가라 롱컨텍스트 할증이 없습니다.

## 접근성과 폰트

- **외부 요청 없음**: 라틴 웹폰트(Archivo, IBM Plex Mono)를 `src/render/fonts/` 에
  넣고 CSS 에 base64 로 심습니다. 한글은 시스템 서체를 씁니다(웹폰트로 받으면 수 MB).
  파일 하나로 완결되고 오프라인에서도 타이포가 유지됩니다. 굵기를 바꿀 때만 `npm run fonts`.
- **대비**: `npm run palette` 가 두 테마의 대비와 램프 단조성 50개 항목을 검사합니다.
  실사용처 기준입니다 — 텍스트 4.5:1, 9~10px 마크 3:1, 장식 테두리·그리드선은 면제.
  테스트에도 묶여 있어 토큰을 바꾸면 깨집니다.
- **랜드마크**: 밴드는 `<main>` 안에 있고 각 `<section>` 은 제목으로 라벨됩니다.
- **키보드**: 30초 갱신이 기간 칩을 다시 만들지 않으므로 포커스가 유지됩니다
  (클릭은 컨테이너에 위임). 표 헤더에는 `scope="col"` 이 붙습니다.

### 워크트리

브랜치별 작업을 리포지토리 밖 형제 디렉터리에서 병행합니다. 안에 두면
`git status` 와 `test/*.js` 글롭이 워크트리를 함께 훑어 결과가 오염됩니다.

```bash
npm run wt:new feat/export-csv   # ../claude-usage-dashboard-worktrees/feat-export-csv
npm run wt:list
npm run wt:rm feat/export-csv    # 커밋 안 된 변경이 있으면 거부된다
npm run wt:rm feat/export-csv force
npm run wt:clean                 # 끊긴 메타데이터 정리 + 병합된 워크트리 안내
```

`wt:clean` 은 아무것도 지우지 않고 정리 대상만 알려줍니다. 삭제는 `wt:rm` 으로
직접 합니다. npm 이 `--force` 를 자기 플래그로 먹으므로 맨 토큰 `force` 를 씁니다.

`.claude/settings.json` 의 `worktree.baseRef` 는 `head` 입니다. 기본값 `fresh` 는
`origin/<기본브랜치>` 를 기준으로 삼는데 이 리포지토리에는 리모트가 없습니다.
리모트를 붙이면 `fresh` 로 바꾸는 편이 낫습니다.

차트 색은 명도 대역, 채도 하한, 색각 이상 분리도(ΔE), 배경 대비를 라이트·다크 양쪽에서
검증한 값입니다. 팔레트를 바꾸면 `src/render/theme.js` 를 수정하고 다시 검증하세요.
