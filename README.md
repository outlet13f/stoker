# claude-usage-dashboard

`~/.claude/projects` 의 Claude Code 세션 트랜스크립트를 직접 읽어 토큰과 환산 비용을 집계하는
로컬 모니터링 대시보드. **네트워크로 나가는 데이터는 없습니다.**

## 빠른 시작

```bash
node src/cli.js --serve --open     # 실시간 대시보드 (기본 포트 7331)
node src/cli.js                    # 정적 HTML 생성 + 터미널 요약
node src/cli.js --json             # 집계 결과를 JSON 으로
```

의존성이 없습니다. Node 20 이상이면 그대로 실행됩니다.

## 대시보드가 답하는 질문

| 밴드 | 질문 | 핵심 지표 |
|---|---|---|
| 진행 중인 5시간 블록 | 지금 안전한가 | 소진 속도, 블록 예상 총액, 상태 등급 |
| 일별 소비와 변화 | 추세는 어떤가 | 일별 비용, 전일·전주 대비 |
| 코드 변경량 | 코드는 얼마나 바뀌었나 | 추가·삭제 줄 수, 건드린 파일, 프로젝트별 순위 |
| 모델 · 프로젝트 · 실행 주체 | 무엇이 비용을 먹는가 | 비용 순위와 비중 |
| 토큰 구성과 캐시 효율 | 토큰은 어디로 가는가 | 토큰 수 기준 / 비용 기준 구성 |
| 시간대별 분포 | 언제 쓰는가 | 24시간 히스토그램 |
| 상위 세션 | 어느 세션이 무거웠는가 | 세션별 비용 |

### 집계 기간 고르기

프리셋(7일 / 30일 / 90일 / 전체) 외에 날짜를 직접 지정할 수 있습니다. 시작일과 종료일을
고르고 `적용` 을 누르면 서버가 그 구간만 다시 집계합니다. 경계는 집계 타임존 기준으로
**시작일 0시부터 종료일 23:59:59.999 까지** 하루 전체를 덮습니다.

주기 갱신이 돌아도 고른 구간은 유지됩니다. `해제` 를 누르면 30일 프리셋으로 돌아갑니다.
정적 HTML 로 내보낸 경우엔 다시 집계할 서버가 없어 날짜 선택이 비활성화됩니다.

### 상태 등급은 어떻게 정해지나

계정마다 한도가 다르므로 절대 기준을 쓰지 않습니다. 진행 중 블록의 **예상 총액**을
**본인의 과거 블록 분포**와 비교합니다.

- `안정` 중앙값 미만
- `주의` 중앙값 ~ 상위 10%
- `높음` 상위 10% 이상

## 옵션

```
--serve            로컬 서버 실행 (변경된 파일만 다시 파싱)
--port <번호>      서버 포트 (기본 7331)
--days <일수>      터미널 요약 기간 (기본 30)
--out <경로>       HTML 저장 위치 (기본 ./dist/dashboard.html)
--tz <타임존>      집계 기준 타임존 (기본: 시스템 설정)
--open             브라우저로 열기
--help, -h         도움말
```

## 집계 방식

- **대상**: `~/.claude/projects/**/*.jsonl` 전부. 메인 세션뿐 아니라
  `<session>/subagents/` 와 `subagents/workflows/` 아래의 서브에이전트·워크플로 트랜스크립트도 포함합니다.
- **코드 변경량**: Edit/Write 툴 결과 레코드에서 뽑습니다. Edit 은 `structuredPatch` 의
  diff hunk 에서 `+`/`-` 줄을 세고, 새 파일 생성은 patch 가 비므로 `content` 전문의 줄 수를 씁니다.
  Claude Code 관리자 화면의 lines added/removed 와 같은 지표입니다.
- **중복 제거**: `message.id` + `requestId` 기준. 같은 응답이 여러 파일에 복제돼도 한 번만 셉니다.
- **5시간 블록**: 첫 활동을 정시에 앵커하고, 5시간 이상 공백이 생기면 새 블록으로 봅니다.
- **증분 파싱**: 파일 크기와 수정시각이 그대로면 다시 읽지 않습니다.
  최초 전체 스캔 약 2.4초(275개 파일 / 622MB), 이후 갱신은 수 밀리초.

## 비용은 "환산 참고값"입니다

공개 API 단가로 계산한 값이며 실제 청구액이 아닙니다. 구독 요금제라면
"같은 작업을 API 로 했다면" 값으로 읽으세요.

| 티어 | input | output |
|---|---|---|
| Opus | $15 / MTok | $75 / MTok |
| Sonnet | $3 / MTok | $15 / MTok |
| Haiku | $1 / MTok | $5 / MTok |

캐시 요금은 input 단가의 배수로 계산합니다: 5분 쓰기 ×1.25, 1시간 쓰기 ×2, 읽기 ×0.1.
단가가 공개되지 않은 모델은 Sonnet 단가로 추정하고 대시보드에 `단가 추정` 으로 표시합니다.
200K 초과 롱컨텍스트 할증은 반영하지 않습니다.

## 구조

```
src/
  constants.js   단가표, 블록 길이, 임계값
  pricing.js     티어 해석과 비용 계산
  parser.js      JSONL 한 줄 → 사용량 레코드
  scanner.js     트랜스크립트 재귀 탐색과 종류 분류
  collector.js   파일 단위 캐시가 있는 증분 수집기
  aggregate.js   합계, 그룹, 일별 시계열, 5시간 블록, 백분위
  report.js      대시보드가 그릴 리포트 객체 조립
  edits.js       코드 변경량 파싱과 집계(추가·삭제 줄 수)
  daterange.js   사용자 지정 날짜 구간 검증과 타임존 경계
  summary.js     터미널 요약 표
  server.js      로컬 HTTP 서버 (/ 와 /api/report)
  cli.js         진입점
  render/        디자인 토큰, 스타일, 클라이언트 렌더러, HTML 조립
scripts/
  worktree.sh    git 워크트리 생성·조회·제거·정리
```

### 워크트리

브랜치별 작업을 리포지토리 밖 형제 디렉터리에서 병행합니다. 안에 두면
`git status` 와 `test/*.js` 글롭이 워크트리를 함께 훑어 결과가 오염됩니다.

```bash
npm run wt:new feat/export-csv   # ../claude-usage-dashboard-worktrees/feat-export-csv
npm run wt:list
npm run wt:rm feat/export-csv    # 커밋 안 된 변경이 있으면 거부된다
npm run wt:rm feat/export-csv force
npm run wt:clean                 # 끊긴 메타데이터 정리 + 병합된 워크트리 안내
```

`wt:clean` 은 아무것도 지우지 않고 정리 대상만 알려줍니다. 삭제는 `wt:rm` 으로
직접 합니다. npm 이 `--force` 를 자기 플래그로 먹으므로 맨 토큰 `force` 를 씁니다.

`.claude/settings.json` 의 `worktree.baseRef` 는 `head` 입니다. 기본값 `fresh` 는
`origin/<기본브랜치>` 를 기준으로 삼는데 이 리포지토리에는 리모트가 없습니다.
리모트를 붙이면 `fresh` 로 바꾸는 편이 낫습니다.

차트 색은 명도 대역, 채도 하한, 색각 이상 분리도(ΔE), 배경 대비를 라이트·다크 양쪽에서
검증한 값입니다. 팔레트를 바꾸면 `src/render/theme.js` 를 수정하고 다시 검증하세요.
